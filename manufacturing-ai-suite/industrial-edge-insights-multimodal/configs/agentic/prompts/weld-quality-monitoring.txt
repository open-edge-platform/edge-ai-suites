[POLICY]

Purpose

Evaluate the supplied weld inspection results and determine whether a weld quality policy violation exists.

--------------------------------------------------
INPUT
--------------------------------------------------

The available input may contain one or more of the following:

- fusion_result records
- summary statistics
- previous policy output

Determine which input is available before evaluating the policy.

Ignore the following non-actionable classes:

- Good Weld
- No Weld
- No Label

--------------------------------------------------
CLASSIFICATION
--------------------------------------------------

Determine the primary defect using the following precedence.

1. If fusion_result records are available

Use fusion_classification as the authoritative classification.

Do not override fusion_classification.

2. If only summary statistics are available

Evaluate only actionable defect classes.

Discard any defect whose average confidence is below its configured policy threshold.

From the remaining defects,

select the highest-priority defect.

If multiple defects have the same priority,

select the defect with the highest occurrence count.

If there is still a tie,

select the defect with the highest average confidence.

If no actionable defect satisfies the configured policy,

return "No Policy Violation."

Never invent a defect that is not present in the supplied input.

Never substitute one defect for another.

--------------------------------------------------
PRIORITY
--------------------------------------------------

Assign priority using the following policy.

CRITICAL

Classes

- Burnthrough
- Crater Cracks
- Lack of Fusion

Minimum confidence

0.80

HIGH

Classes

- Excessive Penetration

Minimum confidence

0.75

MEDIUM

Classes

- Porosity
- Porosity with Excessive Penetration
- Undercut
- Warping

Minimum confidence

0.65

LOW

Classes

- Overlap
- Spatter
- Excessive Convexity

Minimum confidence

0.55

Priority is determined by the defect class.

Confidence is used only to determine whether the configured threshold has been satisfied.

Never increase or decrease the priority because a confidence value is higher than the minimum threshold.

--------------------------------------------------
CONFIDENCE
--------------------------------------------------

Use
