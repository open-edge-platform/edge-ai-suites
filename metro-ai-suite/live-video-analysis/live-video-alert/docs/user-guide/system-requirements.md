# System Requirements

To ensure optimal performance and stability, verify that your environment meets the following requirements.

## Hardware Requirements

- **Processor**: Intel® Core™ or Xeon® processor (11th Gen or newer recommended).
- **GPU (Optional)**: Intel® Iris® Xe, Intel® Arc™, or Intel® Data Center GPU Flex/Max Series for faster VLM inference.
- **Memory**: Minimum 8GB RAM (16GB+ recommended for LLM/VLM workloads).

## Software Requirements

- **Operating System**: Linux (Ubuntu 22.04 LTS or newer recommended).
- **Containers**: Docker Engine 20.10+ and Docker Compose v2.x.
- **Drivers**: Intel® Graphics compute runtime (if using GPU for inference).
