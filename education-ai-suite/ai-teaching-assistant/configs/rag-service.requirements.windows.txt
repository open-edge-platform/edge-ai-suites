# =============================================================================
# AI Teaching Assistant — rag-service dependencies (Windows / local-only)
# =============================================================================
# This is a curated subset of the voice-enabled-interactions submodule's
# rag-service/requirements.txt. The agentic/ordering stack (google-adk,
# litellm, fastmcp, ...) is intentionally omitted because:
#   * ATA disables the ordering agent (KIOSK_CORE_ORDERING_ENABLED=false and
#     the RAG agent endpoint is unused), and
#   * litellm builds a Rust extension that fails to install on Windows without
#     a full Rust/Cargo toolchain.
# rag-service imports the agentic package lazily (only when the agent endpoint
# is called / bootstrapped), so it starts and serves RAG queries fine without
# these packages present.
# Keep the versions below in sync with the submodule's requirements.txt.
# =============================================================================
