# ROS 2 Runtime

The Robotics AI Suite uses ROS 2 Jazzy Jalisco on the supported Canonical Ubuntu
24.04 LTS platform. Before continuing, review the
[System Requirements](../../platform_foundation/system_requirements.md).

## Install ROS 2 Jazzy

**ROS 2 is included in the Robotics AI Suite. If you've installed the suite using the [Getting Started](../../platform_foundation/getting_started.md) guide, then you already have ROS 2 installed and setup for your supported platform.**

Follow the official
[ROS 2 Jazzy installation instructions for Ubuntu](https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html).



## Blueprint-Specific Middleware

Blueprints can add robot-specific drivers, bridges, and runtime packages. Refer
to the relevant Blueprint before installing those components:

- [Autonomous Mobile Robot architecture](../../hardware_blueprints/amr/index.md)
- [Reference Implementations](https://docs.openedgeplatform.intel.com/dev/ai-suite-robotics.html)
