# CAN Bus

## CAN Connector (J1)

The kit provides two isolated CAN FD channels on the J1 connector.

| Pin | Signal | Pin | Signal |
| :-- | :-- | :-- | :-- |
| A1 | RX_1# | B1 | RX_2# |
| A2 | DCD_1# | B2 | DCD_2# |
| A3 | GND | B3 | GND |
| A4 | CAN_FD1_H | B4 | CAN_FD2_H |
| A5 | CAN_FD1_L | B5 | CAN_FD2_L |
| A6 | GND_ISO | B6 | GND_ISO |
