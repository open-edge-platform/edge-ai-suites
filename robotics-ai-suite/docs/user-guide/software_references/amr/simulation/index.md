# Simulation Software References

In this software reference series, you'll learn how to simulate robots powered by Intel's Robotics AI Suite in Gazebo, the companion simulator to ROS.

First, you'll begin with a simple introduction to Gazebo, learning how to simulate a digital twin to a real robot to test our your robotics applications.
Next, you'll combine everything you learned by running the `wandering` pipeline in simulation, exploring how intelligent sensing gives your software context of the physical world around it, and how you can use Robotics AI Suite ingredients for a production ready autonomous platform.

## [Simulating robots with Gazebo](basic_sim.md)
In this software reference, you'll learn how to simulate your robot using Gazebo. You'll learn how a ROS 2 enabled solution can be simulated by seeing a demonstration pipeline that utilizes a fixed conveyor, a stationary arm, and a mobile autonomous robot (AMR) to transfer material across a workspace.

## [Simulating `wandering` in Gazebo](wandering_sim.md)
In this software reference, you'll use the `wandering` pipeline, to demonstrate a multi-featured multi-sensor algorithmic-driven pipeline optimized with Intel oneAPI in your simulation environment. This will teach you how to chain together complex processes to craft a fully featured robotics pipeline.

## Next Steps
Now that you've experimented with Robotics AI Suite in simulation, it's time to apply those to a real-world deployed robot. The [deployment learning path](../deployment/index.md) will help you set up your robot and see Robotics AI Suite in use in a production ready pipeline.
